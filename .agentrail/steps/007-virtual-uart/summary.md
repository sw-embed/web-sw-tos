Added crates/swtos-host/src/uart.rs, the in-process virtual UART replacing the pty: two byte queues, with the target-bound queue carrying a per-byte cycle budget so one queue serves both framed traffic (500,000 cycles) and the 100 Hz scheduler heartbeat (20,000 cycles). Pacing is in the type because SWTOS input rings hold 16 bytes and overflow silently. 4 tests covering ordering with mixed budgets, drain semantics, duplex independence, and binary transparency over all 256 byte values including a literal a5 5a sync sequence. swtos-host is all-PASS on sw-checklist; totals unchanged at 23/1/3.
