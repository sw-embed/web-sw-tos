Pane-focus buttons build from the live layout. Corrected two CLAUDE.md rules the fix exposed: preventDefault is not sufficient for a browser-claimed key, and 'no mouse' is about the character screen, not page chrome. Derived a hardcoded prefix byte in keys.rs. Extracted App::tick to keep update() in budget. Deployed to the nightly channel; NOT verified in a real browser (Chrome extension not connected).
